# Marcus OS cloud

This is the Vercel application for Marcus OS. Its source belongs to the parent `hermes-dashboard` repository on `main`.

Vercel project: `hermes-dashboard`. Production root directory: `cloud`.

Run `npm ci`, then `npm run dev` in this folder. Production uses server-only settings already configured in Vercel. Do not copy Mac environment files or data into this folder.

See the parent [hosting guide](../CLOUD-HOSTING.md) for authentication, relay behavior and offline limits.
